# Neon Reels — Unity Slot Machine Assignment

This repository contains `NeonReels-Submission.zip`, which includes the complete Unity 6.4 project and the verified WebGL player.

## Run in Unity

1. Download and extract `NeonReels-Submission.zip`.
2. Open the extracted project folder in Unity `6000.4.10f1`.
3. Open `Assets/Scenes/NeonReels.unity` and press Play.

## Run the WebGL player

After extracting the archive, serve `Build/WebGL/` from a static HTTP server and open its `index.html`.

## Game features

- Three independently animated reels with randomized outcomes
- Bet sizing, credits, and last-win display
- 12× payout for triple 7s, 8× for triple diamonds, 5× for other triples
- Responsive neon arcade cabinet drawn with procedural art

The linked Drive asset archive was unavailable, so the project uses original procedural artwork.
