# Neon Reels

A compact, self-contained Unity slot machine assignment project. The scene is generated from code so the project needs no downloaded packages, texture sets, or setup steps beyond opening it in Unity.

## Game overview

Neon Reels is a three-reel arcade slot machine. Start with 1,000 credits, set a bet from 10 to 100, then spin. Each reel uses Unity's random number generator and stops independently with a staggered animation. A win requires all three symbols to match.

| Combination | Payout |
| --- | ---: |
| Three 7s | 12× bet |
| Three diamonds | 8× bet |
| Any other triple | 5× bet |
| Any other result | No payout |

Payouts are credited after the third reel stops. The six equally weighted symbols give a 1 in 216 chance of an exact triple per spin. There are no controlled near misses.

## Run in Unity

1. Open this folder in Unity 6.4 (`6000.4.10f1`).
2. Open `Assets/Scenes/NeonReels.unity` and press Play.
3. Use the `−` and `+` controls to set the bet. Click **SPIN** or press Space.

The game uses Unity's immediate GUI and draws its own cabinet and symbol art. The layout scales to fit different aspect ratios. The assignment's linked Drive asset package could not be retrieved in this environment, so this version uses original procedural art instead of those supplied files.

## Build and run the WebGL player

The startup scene is enabled in `ProjectSettings/EditorBuildSettings.asset`. The Unity Editor successfully generated the WebGL player (19,800,568 bytes). The built player is included in the submission ZIP and excluded from version control; to rebuild it, open the project in Unity and choose **Neon Reels → Build WebGL**. Choose **Neon Reels → Create Starter Scene** to regenerate the scene.

Once generated, serve the project root with a static HTTP server. For example, with Python installed:

```sh
python -m http.server 8000
```

Open the generated WebGL `index.html` at `http://localhost:8000/Build/WebGL/`.

## Bonus features

- Bet sizing, credit balance, and last-win display.
- Staggered reel stops and animated symbol cycling.
- Higher payouts for triple 7 and triple diamond.
- Spacebar spin shortcut and clear payout table.

## Approach

The game loop is kept in one focused `MonoBehaviour`, with a small `Reel` model for each independent animated reel. The RNG chooses each final symbol at spin start. The reels animate separately, and win evaluation runs only after all three have stopped. This keeps presentation timing separate from outcome selection and payout calculation.

The editor bootstrap script can recreate the scene and WebGL build. A ready-to-open scene is included so the game is available as soon as Unity imports the project.
